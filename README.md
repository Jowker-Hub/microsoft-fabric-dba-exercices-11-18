# Exercices Microsoft Fabric pour DBA — 11 à 18

Ce dépôt temporaire contient les exercices pratiques Microsoft Word 11 à 18 de la formation **Microsoft Fabric pour les DBA**.

## Contenu

- Exercice 11 — Créer un modèle Direct Lake avec RLS
- Exercice 12 — Déployer de DEV vers TEST
- Exercice 13 — Observer la consommation de capacité
- Exercice 14 — Établir le lineage de référence
- Exercice 15 — Restaurer une table Delta
- Exercice 16 — Restaurer une SQL database
- Exercice 17 — Restaurer un Warehouse
- Exercice 18 — Récupérer un item supprimé

L’exercice 19 n’est pas inclus : aucun document Word n’est actuellement disponible pour cet exercice.

## Utilisation

Téléchargez les fichiers `.docx` du dossier `exercices/`, ou l’archive ZIP disponible à la racine pour récupérer l’ensemble en une seule fois.

Les fonctionnalités et libellés Microsoft Fabric peuvent varier selon le tenant, la capacité, la région et l’évolution du produit. Les mentions `[À TESTER]` signalent les éléments qui doivent être confirmés dans l’environnement utilisé.

## Diffusion

Mise à disposition temporaire pour les participants à la formation.
